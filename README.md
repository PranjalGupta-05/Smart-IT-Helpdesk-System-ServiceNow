# Smart IT Helpdesk System | ServiceNow

## 📌 Project Overview

The **Smart IT Helpdesk System** is a ServiceNow-based IT Service Management (ITSM) application developed as a hands-on practice project to strengthen understanding of workflow automation, ticket management, and enterprise service processes.

This project automates ticket handling by implementing:

* Automated ticket assignment
* Priority-based routing logic
* Workflow automation using Flow Designer
* Email notifications
* Dashboard analytics and reporting
* UI Policies and validations

The application simulates a real-world IT helpdesk environment where support tickets are created, categorized, prioritized, assigned, and monitored through automated workflows.

# 🔄 Workflow Overview

## Ticket Lifecycle

1. User creates ticket
2. Ticket categorized
3. Flow Designer triggers automation
4. Ticket assigned automatically
5. Priority logic applied
6. Notification sent
7. Dashboard updated
8. Ticket resolved/escalated
